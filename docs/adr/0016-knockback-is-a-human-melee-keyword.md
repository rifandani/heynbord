# Knockback is a Human melee Keyword, and it cannot push a Wall

Knockback is a Human Main Keyword, in the same way [ADR-0015](0015-poison-is-elf-summon-is-undead-and-last-breath-is-orc.md) gives a Main Keyword to one Race. After a melee Unit with Knockback deals attack damage above 0, the enemy Unit is Pushed toward its own Hero. Knockback is melee only, because a Ranged push can lock a melee Unit out of reach in each Turn. A Unit with Wall is never Pushed, so that a Wall always blocks its Lane.
