# Poison is Elf, Summon is Undead, and Last Breath is Orc

Poison joins Elf in v1. Summon moves from Elf to Undead, and Last Breath moves from Undead to Orc. Last Breath stays an on-death hit or Token, because Rebirth is already the one-time return at 1 HP. Poison is its own stack, so it is a separate Status from Burn. The Race that gives the Keyword up changes its cards, and other Races may still borrow it.
