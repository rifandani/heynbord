# Bleed is a Feral Keyword on two cards, not a Main Keyword

> Gorehorn Red Maw has Bleed 2 since 2026-10-21 — see [ADR-0056](0056-each-specialist-has-a-second-keyword.md) and [Amendments](#amendments).

**Bleed N** makes the enemy Unit **Bleeding**: it gets half of each heal, rounded down, and Bleeding does no damage. Bleed is a counter to heal plans, such as Elf healers and Feral Regeneration. It is Feral, because claws and fangs suit it, but only the Frostfang Lynx and Old Frostmaw have it. It is not a Main Keyword, so the rule of [ADR-0017](0017-sabotage-and-hobble-are-goblin-and-trample-is-feral.md) stays: one new signature Keyword for each Race, and the Feral signature is Trample. Wild Hunt already wins 84% to 98% of its Matchups, so we add Bleed on few cards first. If the Matchups show that Bleed is good for Feral, a new ADR can make it a Main Keyword.

Heals round down, so that Bleeding stops Regeneration 1. With rounding up, Bleed has no effect on most cards that heal now.

## Considered Options

- **Bleed as a second Feral Main Keyword.** Rejected for now. It breaks ADR-0017, and Feral is already too strong.
- **Bleed for Undead or Orc.** Rejected. The Feral creatures with claws and fangs suit the name best.
- **Bleeding that also deals damage.** Rejected. Damage over time is already Burn and Poisoned.

## Amendments

- **2026-10-21: Gorehorn Red Maw has Bleed 2.** [ADR-0056](0056-each-specialist-has-a-second-keyword.md) gives the Feral Specialist a fixed Bleed 2. Bleed stays a Feral Keyword and not a Main Keyword, and the Bleed of the Frostfang Lynx and Old Frostmaw still follows the Rank table: 1 up to Rare, 2 at Epic and 3 at Legendary.
